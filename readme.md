# Certification JavaScript Projects

Ce dépôt regroupe l'ensemble des projets réalisés dans le cadre de la certification **JavaScript Algorithms and Data Structures** de **freeCodeCamp**.

Chaque projet a été développé en respectant les spécifications imposées par FreeCodeCamp afin de mettre en pratique les concepts fondamentaux de JavaScript, la manipulation du DOM, les événements, les API du navigateur et le développement d'applications web interactives.

---

# Technologies utilisées

L'ensemble des projets utilise les technologies suivantes :

- HTML5
- CSS3
- JavaScript (ES6)

---

# Projets réalisés

## 1. Drum Machine

Boîte à rythmes interactive permettant de jouer des sons avec le clavier ou la souris.

**Compétences développées :**

- Lecture de fichiers audio
- Événements clavier
- Événements souris
- Manipulation du DOM

---

## 2. Markdown to HTML Converter

Convertisseur Markdown vers HTML avec aperçu en temps réel.

**Compétences développées :**

- Expressions régulières
- Conversion Markdown
- Manipulation du DOM
- Mise à jour dynamique de l'interface

---

## 3. Voting System

Application simulant un système de vote permettant d'enregistrer des votes et d'afficher les résultats.

**Compétences développées :**

- Manipulation des objets
- Gestion des tableaux
- Algorithmes de comptage
- Logique métier

---

## 4. Bank Account Management Program

Application simulant la gestion d'un compte bancaire avec dépôt, retrait et consultation du solde.

**Compétences développées :**

- Programmation orientée objet
- Encapsulation des données
- Gestion des opérations financières
- Validation des entrées

---

## 5. Weather App

Application météo récupérant les conditions météorologiques d'une ville grâce à une API.

**Compétences développées :**

- Consommation d'API REST
- JavaScript asynchrone (Fetch / Promises)
- Manipulation du DOM
- Gestion des réponses JSON
